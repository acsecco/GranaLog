# GranaLog

Sistema web para universitários registrarem suas entradas e saídas de dinheiro, organizarem os lançamentos por categoria e visualizarem, em um gráfico, para onde o dinheiro está indo.

## Funcionalidades planejadas

- Registrar entradas e saídas;
- Classificar cada lançamento em uma categoria;
- Visualizar a porcentagem de gastos por categoria em um gráfico.
